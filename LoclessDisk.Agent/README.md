# Проверка C#-агента в WinPE

Прототип открывает окно Win32 и проверяет HTTP-соединение с Sharp. Для проверки через PXE он читает `fogs-agent.json` и запрашивает состояние задачи. Запрос не меняет задачу и ничего не записывает на клиентский диск.

- Для проверки окна в обычной Windows или WinPE запустите `LoclessDisk.Agent.exe --demo`.
- Для ручной проверки сети укажите адрес панели Sharp, например `LoclessDisk.Agent.exe --probe http://192.168.1.10:8080/health`. Подставьте фактический порт панели.
- Для PXE на отдельном стенде сохраните копию действующего `EFI\agent\partclone.exe`. Положите на его место C#-сборку под тем же именем, поставьте задачу «Проверка связи» и загрузите тестовый ПК. Появившееся окно подтверждает запуск GUI. Строка `HTTP 200` подтверждает, что запрос дошёл до Sharp. Задача останется в очереди, её можно отменить после проверки. Верните рабочий бинарник перед использованием других задач.

GitHub Actions собирает Native AOT для `win-x64` и сохраняет `LoclessDisk.Agent.exe` в артефакте `locless-disk-agent-winpe-x64`. Для локальной сборки кода в WSL достаточно `dotnet build LoclessDisk.Agent`.
