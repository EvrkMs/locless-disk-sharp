# Работа с репозиторием Locless Disk (Sharp)

- Основной репозиторий C#-проекта — EvrkMs/locless-disk-sharp. Ветка для обновлений тестового стенда — main, пока пользователь не указал другую.
- Перед изменениями и перед публикацией проверяй ветку, origin и рабочие изменения. Перед отправкой получи актуальное состояние целевой ветки и сохрани уже опубликованные коммиты и локальные правки пользователя.
- После завершения и проверки законченного изменения сам предложи коммит. Укажи короткое сообщение коммита, целевую ветку и результат проверки. Если пользователь уже попросил сделать коммит или запушить, выполни указанное действие без повторного запроса.
- Включай в коммит только файлы текущей задачи. Собранные файлы, локальные базы и материалы стенда остаются локально. После публикации проверь удалённую ветку и сообщи ссылку на коммит.
- Для dotnet restore и dotnet build используй Windows PowerShell или cmd в этой папке. Интеграционный тест восстановления VHD запускай в WSL Codex. Не запускай PXE-службы на хосте с CCBoot для локальных проверок.
