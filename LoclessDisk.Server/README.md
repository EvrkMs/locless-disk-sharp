# LoclessDisk.Server

ASP.NET Core и .NET 10. Сервер слушает 127.0.0.1:8081. Для запуска рядом с Go-сервером задайте другой порт, например:

```bash
dotnet run --project LoclessDisk.Server -- --AdminPort=18081
```

На главной странице сохраните абсолютный путь к папке образов и нажмите «Сканировать».
Поиск идёт по вложенным папкам. Слои связываются по ID, затем библиотека проверяет цепочку и индекс.
Ошибки отдельных файлов отображаются в результате сканирования.
Повторное сканирование обновляет каталог, включая удалённые с диска версии.

SQLite хранится в data/catalog.db. Путь можно задать через CatalogDatabase.
Миграции применяются при запуске. Запускайте из папки установки, чтобы использовать её data.

- GET /api/settings, PUT /api/settings с JSON {"imageRoot":"..."}
- POST /api/images/scan с JSON {}
- GET /api/images
- GET /api/images/{id}?version={versionId}

## PXE на стенде

По умолчанию PXE выключен. Чтобы включить TFTP и proxyDHCP, добавьте в конфигурацию сервера:

```json
{
  "Pxe": {
    "Enabled": true,
    "BindAddress": "192.168.88.105",
    "EfiRoot": "EFI",
    "BootFile": "ipxe-shim.efi",
    "BootScriptUrl": "http://192.168.88.105:8080/boot.ipxe?mac={mac}",
    "AllowedMacs": ["00:11:22:33:44:55"]
  }
}
```

- Укажите IPv4 сетевой карты стенда, путь к EFI и MAC тестового ПК. Пустой список MAC оставляет proxyDHCP без ответов.
- TFTP читает файлы из EFI, относительный путь считается от рабочего каталога сервера. `autoexec.ipxe` генерируется из `BootScriptUrl`.
- proxyDHCP слушает UDP 67 и 4011, TFTP слушает UDP 69. Основной DHCP по-прежнему должен выдавать клиентам IP.
- Укажите действующий HTTP-адрес iPXE-скрипта. Выдача WinPE и задач по HTTP в C# пока не перенесена.
- При занятом порте служба пишет ошибку в журнал и повторяет попытку через 5 секунд. На сервере CCBoot оставьте секцию выключенной.
